# Código de Conducta

## Nuestro compromiso

Como responsables y colaboradores de este proyecto de investigación, nos
comprometemos a mantener un ambiente de trabajo respetuoso, profesional y
libre de acoso para todas las personas que contribuyan mediante issues,
pull requests, revisiones de código o cualquier otra forma de participación.

## Estándares esperados

Comportamientos que contribuyen a un ambiente positivo:

- Usar lenguaje respetuoso e inclusivo.
- Aceptar críticas constructivas sobre el código y la metodología.
- Enfocar el desacuerdo en argumentos técnicos y científicos, no en
  personas.
- Reconocer errores propios y corregirlos con transparencia (relevante en
  un proyecto de investigación reproducible).

Comportamientos inaceptables:

- Comentarios despectivos, ataques personales o acoso de cualquier tipo.
- Publicar información privada de terceros sin consentimiento explícito.
- Alterar o falsificar resultados experimentales, métricas o checkpoints
  reportados.

## Alcance

Este código de conducta aplica a todos los espacios del proyecto: el
repositorio de código, issues, pull requests y cualquier canal de
comunicación asociado.

## Aplicación

Los casos de comportamiento inaceptable pueden reportarse al responsable
del proyecto (ver `CONTRIBUTING.md`). Todas las quejas serán revisadas de
forma confidencial.
